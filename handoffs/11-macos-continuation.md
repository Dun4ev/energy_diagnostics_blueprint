# Передача проекта для продолжения на MacBook

База исходных изменений: `f1263096cf38a70e1421059142e92a25106203c2`, ветка `main`. Этот документ описывает состояние перед коммитом и отправкой; итоговый идентификатор коммита смотрите в `git log`.

## Что сделано

- Сохранены исправления склонений счетчиков и тесты для них.
- Добавлен `/stand`: запись восьми учебных эпизодов на 180 секунд, управление показом и отдельный переход к живому SIMULATION-запуску. Пакет создается на временной SQLite-базе из синтетических observations. Детали и ограничения: [10-stand-mode.md](10-stand-mode.md), [RFC-stand.md](RFC-stand.md).
- Добавлена [инструкция стенда](../docs/runbook/STAND.md) и [сценарий показа функций](../docs/runbook/PRESENTATION.md): действия в интерфейсе, смысл экранов, роли, результаты и восстановление после ошибок.
- Сохранены исходники и готовые версии роликов: [презентация продукта](../pieces/energy-product-film-v3/renders/final.mp4), [показ интерфейса](../pieces/energy-motion-v2/renders/share.mp4), [первая версия](../pieces/energy-explainer/renders/share.mp4). Сценарии, иллюстрации, музыка и исходный код находятся рядом с роликами; временные кадры и локальные зависимости исключены из Git.
- Добавлена [инструкция для Mac](../docs/runbook/MAC.md), в том числе где брать локальные пароли и почему история базы не переносится через Git.

## Совместимость и фактические проверки

Новых бизнес-API, полномочий и миграций для стенда не добавлялось. Существующие DTO и обозначения режимов сохранены. Код frontend и текущие файлы пакета проверены в существующих локальных контейнерах без сети:

- `npm test`: 51 тест пройден.
- `npm run build`: typecheck и Vite прошли; Vite предупредил о крупном чанке графиков.
- `python -m unittest discover -s /app/tests/stand -p test_package.py -v`: 4 теста пройдены, включая DTO, hashes observations и отсутствие полей учетных данных/truth в записи.
- `GET /api/v1/health`: `ok`, база и worker готовы, советчик без команд и без внешнего AI.
- Два MP4 и один более ранний вариант сохранены с исходниками; проверки роликов описаны в их `LOG.md`. Музыкальные дорожки проверены технически, субъективное прослушивание не выполнено.
- Локальный PostgreSQL dump создан в `infra/.env.backups/` и проверен через `pg_restore --list`. Он игнорируется Git; полноценное восстановление этого архива не выполнялось.

На Mac и Apple Silicon сборка, GUI и роли в этой сессии не проверялись. В ранее проверенном печатном виде правая часть графика на первой странице обрезалась. Автоматическая пауза стенда при реальном скрытии вкладки и искусственная ошибка worker отдельно не воспроизводились. Другие границы и ранее выполненные проверки перечислены в `10-stand-mode.md`.

## Следующее действие

На Mac получить изменения и запустить проект по [MAC.md](../docs/runbook/MAC.md). Пройти [PRESENTATION.md](../docs/runbook/PRESENTATION.md) на целевом компьютере, проверить печать и при необходимости доработать отдельный ролик с демонстрацией функций. Для переноса существующей истории нужна отдельная защищенная передача и безопасное восстановление; обычный Git pull переносит только файлы репозитория.

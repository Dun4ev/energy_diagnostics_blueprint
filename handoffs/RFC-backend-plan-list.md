# RFC: список проектов для восстановления UI после перезагрузки

## Проблема

Frozen OpenAPI G1 содержит только `GET /api/v1/work-plans/{id}`. После перезагрузки UI не может узнать ID ранее созданного проекта по случаю, если не хранит его локально. Такой локальный ID не является надежным источником состояния.

## Предлагаемое изменение

Добавить `GET /api/v1/work-plans?scenarioRunId=<id>&caseId=<optional>&limit=<1..1000>&offset=<0..>` с ответом `Envelope[Page[WorkPlan]]`. Новый DTO не нужен. Доступ по существующему `read`; данные строго ограничены `scenarioRunId`. Неизвестный `caseId` возвращает 404. Реализация уже находится в `apps/api/main.py` этапа 04.

## Влияние

Интегратор обновляет канонический экспорт `contracts/openapi.json`, генерирует TS клиент и меняет фронтенд для поиска существующего проекта. Совместимость старого маршрута сохранена; миграция БД не нужна сверх общей схемы этапа 04. `apps/api/schema.py` также меняет `x-implementation-status` на фактический статус маршрутов; это требует регенерации export интегратором.

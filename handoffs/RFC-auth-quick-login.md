# Локальное переключение тестовых пользователей

Последовательное изменение интегратора по запросу пользователя. База: f1263096cf38a70e1421059142e92a25106203c2.

LoginRequest получает необязательный quickLogin=false; Health получает demoQuickLoginEnabled=false. Существующие запросы совместимы. Быстрый вход разрешен сервером только при DEMO_QUICK_LOGIN=true и только для включенных demo-ролей. Пароли остаются в env, не передаются в интерфейс. При смене пользователя старая сессия отзывается, новая имеет реальные права и CSRF. Бизнес-контракты и проверки переходов не меняются. URL и выбранный запуск сохраняются при перезагрузке.

Это локальный тестовый режим с доступом ко всем включенным ролям. По умолчанию выключен. Отключение флага возвращает проверку паролей; существующие сессии продолжаются до выхода/истечения.

Команды для копирования

Выполняйте в Терминале. Docker Desktop должен быть запущен.

cd /Users/j15/Documents/Code_and_Scripts_local/prototypes/energy_diagnostics_blueprint
python3 scripts/init_local_env.py
docker compose --env-file infra/.env -p energy-diagnostics -f infra/compose.yaml up --build -d --wait

Проверки работающего приложения. Нужен uv; live-проверки создают локальные записи.

uv sync --frozen
uv run --frozen python scripts/smoke_local.py
uv run --frozen python scripts/check_live_workflow.py

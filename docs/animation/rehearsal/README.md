# Полная репетиция: Canvas 16:9

Открыть index.html. Самодостаточный файл: сеть и внешние библиотеки не нужны.

38 шагов, 30 fps, 12960 кадров, 7 мин 12 с. По умолчанию остановлен. «Далее»/«Назад»/выбор шага проигрывают один шаг и останавливаются. «Повторить шаг» повторяет текущий; «Автопоказ» идет до конца, повторное нажатие ставит на паузу. Ползунок позволяет найти произвольный кадр. При reduced motion ручной выбор сразу показывает конец шага.

Под Canvas: точные названия полей, готовые учебные тексты, ожидаемый результат, реплика. Это схема, не видеозапись интерфейса. Основной сценарий: Docker, env, Compose, engineer, SIMULATION, очередь, разбор, наблюдение, отдельный синтетический протокол, подтверждение случая, план, viewer, approver, technician, два результата шагов, завершение плана, отдельное закрытие, история, экспорт, проверки и stop.

## Программный доступ

- `?f=3600&s=7&w=1920&ar=16:9`: статический кадр.
- `?grid=24`: контрольный лист.
- `window.RISO.total`, `.plates`, `.frame(n,width,seed)`, `.contact(count,cellWidth)`.
- `window.__ready === true` означает готовность отрисовки.
- Кадры экспортируются Canvas.toDataURL, не снимком страницы.

scenes.json дублирует встроенные данные для удобного чтения. Runtime его не загружает. При редактировании менять встроенный массив scenes в index.html и синхронизировать JSON.
